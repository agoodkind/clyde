# Superseded generic LMS search cutover plan

The [shared search coordination plan](2026-09-27-shared-search-coordination.md) controls execution. The [Clyde design](../specs/2026-09-27-embedded-search-design.md) defines current search behavior. The [query](2026-09-27-embedded-conversation-query.md) and [runtime](2026-09-27-embedded-conversation-runtime.md) plans define Clyde work. The historical LMS RPC, allowed-ID preparation from the raw index, fixed depth, and production cutover steps do not apply. Complete eligible pages, typed failures, existing public fields, and context verification remain acceptance requirements in the current plans.
